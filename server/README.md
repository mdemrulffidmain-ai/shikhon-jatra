# শিখন সার্ভার

একাউন্ট ও অগ্রগতি সিঙ্কের ছোট সার্ভার। বাইরের কোনো প্যাকেজ লাগে না, শুধু Node 20 বা নতুন।

```bash
node server/server.mjs                  # http://localhost:8787
PORT=3000 DATA_DIR=/var/shikhon node server/server.mjs
```

- তথ্য থাকে `DATA_DIR/users.json` ফাইলে (পাসওয়ার্ড scrypt দিয়ে হ্যাশ করা)। গোপন চাবি `secret.key` একই ফোল্ডারে তৈরি হয়; `SECRET` পরিবেশ চলক দিয়েও দেওয়া যায়।
- API: `POST /api/register`, `POST /api/login`, `GET|PUT /api/sync`, `POST /api/delete`, `GET /api/ping`।
- ভুল পাসওয়ার্ড ৮ বারের পর ১৫ মিনিট আটকানো, প্রতি আইপিতে মিনিটে ৬০ অনুরোধ, অনুরোধের সর্বোচ্চ আকার ৬০০ কিবি।
- সার্ভারে শুধু অগ্রগতি যায় (`src/lib/merge.js` এর `SYNC_KEYS`)। পিন, ফোনের সময়, API কী যায় না।

## প্রকৃত ব্যবহারে
- **অবশ্যই https দিয়ে চালাও।** সার্ভারের সামনে Caddy বা nginx দিয়ে সার্টিফিকেট বসাও, অথবা Render, Railway, Fly.io এর মতো সেবায় চালাও (সেখানে https আপনাআপনি থাকে)। http দিয়ে পাসওয়ার্ড খোলা অবস্থায় যায়।
- ডিস্ক স্থায়ী রাখো (`DATA_DIR`), না হলে সার্ভার আবার চালু হলে একাউন্ট হারাবে।
- এটি একটি ফাইলে তথ্য রাখে। কয়েক হাজার ব্যবহারকারী পর্যন্ত চলে; এর বেশি হলে ডেটাবেসে সরাতে হবে।
- শিশুদের তথ্য রাখলে আপনার দেশের আইন (তথ্য সুরক্ষা, অভিভাবকের সম্মতি) আপনার দায়িত্ব। অ্যাপে ১২ বছরের কম বয়সীদের জন্য নতুন একাউন্টে "বড় কারো সম্মতি" বোতাম আছে, কিন্তু এটি আইনি যাচাই নয়।
- পাসওয়ার্ড ভুলে গেলে ফেরত পাওয়ার ব্যবস্থা নেই (ইমেইল নেই বলে)। ব্যবহারকারীকে বলে দাও।

অ্যাপ বিল্ডের সময় ঠিকানা বসাতে: `VITE_SERVER=https://আপনার-সার্ভার npm run build`। না দিলে ব্যবহারকারী অ্যাপের ভেতরে ঠিকানা লেখে।
